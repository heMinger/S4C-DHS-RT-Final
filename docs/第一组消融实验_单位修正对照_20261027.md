# 第一组消融实验：原实现 vs DA3 单位修正（z→距离）

日期：2026-10-27
目标：量化「DA3 轴向 z-buffer 未转沿射线距离」这一单位错误造成了多少损失。

## 1. 背景

详见《DA3轴向Z未转沿射线距离_采样中心偏移分析_20261025.md》。

- DA3 输出轴向 z-buffer（`z = d_ray · cosθ`），代码原实现直接把它当沿射线距离用，
  导致采样中心偏近，偏移随像素偏离图像中心单调增大。
- 修正：在 sampler 注入点，用相机坐标系 `cosθ` 计算 `d_ray = z / cosθ`，
  仅用于 DHS 自适应采样；原始 z 深度仍供深度损失/评测使用。
- 已加单变量开关 `da3_z_to_distance`（默认 true = 修正后），
  由 `configs/exp_s4c_dhs_rt_e1.yaml` → `model_conf.da3_z_to_distance` 控制。

## 2. 实验设计（单变量对照）

| 组 | 配置 | da3_z_to_distance | 含义 |
|---|---|---|---|
| A（原实现，对照） | `exp_ablation_z2dist_orig.yaml` | **false** | 直接用轴向 z 当沿射线距离（有单位 bug） |
| B（修正后） | `exp_ablation_z2dist_fixed.yaml` | **true** | `z / cosθ` → 沿射线距离（采样中心正确） |

两组**共同参数**（保持与 E1 完全一致，仅切换开关）：

- 基座：S4C + DHS（`adaptive_sampling=true`）+ RT 图像特征版（E1，`ray_attention.enabled=true`）
- warm-start：`resume_from=/home/lmh/s4c/out/training_checkpoint_176000.pt` + `reset_training_state=true`
  （只加载模型权重，optimizer/lr_scheduler/iteration 从头；两组初始化一致）
- `batch_size=8`、`accumulation_steps=2`、`ray_batch_size=4096`、`patch_size=8`、
  `n_surface_samples=32`、`n_global_samples=32`、其余 model/loss/scheduler/renderer 全同。

训练步数（本组新增控制）：

- `stop_iteration: 5000`（约 0.41 epoch；E1 训练速度约 400 iter/h → 每组约 12.5 小时）
- `validate_every: 1000`（在 5000 iter 内得到 5 个验证点：1000/2000/3000/4000/5000）
- `checkpoint_every: 500`（default.yaml，自动保存 `training_checkpoint_*.pt` 供中间对比）

> 若需更稳，可命令行覆盖 `stop_iteration=8000` 或 `10000`。

## 3. 训练命令（在交互终端执行，需 GPU）

```bash
cd /home/lmh/s4c-DHS-RayTransformer

# A（原实现，对照）
python train.py -cn exp_ablation_z2dist_orig

# B（修正后）
python train.py -cn exp_ablation_z2dist_fixed
```

输出目录（自动带时间戳）：

- A：`out/ablation_z2dist/orig/ablation_z2dist_orig_backend-None-1_<时间戳>/`
- B：`out/ablation_z2dist/fixed/ablation_z2dist_fixed_backend-None-1_<时间戳>/`

> 两组**串行**执行（每组约 29.6 GiB，A6000 48 GiB 无法并行）。

## 4. 评测

训练完成后对两组最终 checkpoint（及中间 checkpoint）跑 SSCBench 评测：

```bash
cd /home/lmh/s4c-DHS-RayTransformer

# 以 A 为例（B 同理，替换 -cp 路径）。数据根/GT 路径与之前 E1 评测相同。
python scripts/benchmarks/sscbench/evaluate_model_sscbench.py \
    -ssc <sscbench_data_root> \
    -vgt <voxel_gt_path> \
    -cp out/ablation_z2dist/orig/ablation_z2dist_orig_backend-None-1_<时间戳>/training_checkpoint_5000.pt \
    --full
```

评测协议：50 帧 / voxel 0.2m / 排除遮挡 / 膨胀（见 commit e84941e；
`--full` 走全量，省略则用 `DATASET_LENGTH` 截断）。

对比指标：**IoU、mIoU**（论文目标：两者都超过 S4C 基线；S4C+DHS+RT 是历史基准 Ours）。
