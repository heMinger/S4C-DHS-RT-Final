# 与 S4C、ViPOcc 的对比分析

> 训练设置、射线采样与关键实例占比的对比。

---

## 一、与原始 S4C 的对比

### 1.1 原始 S4C 来源

- **代码**：https://github.com/ahayler/s4c
- **论文**：Self-Supervised Semantic Scene Completion with Neural Fields (arXiv:2310.07522)

### 1.2 训练设置对比（KITTI-360）

| 项目 | 原始 S4C (exp_kitti_360) | 本项目 (s4c-adaptive-sampling1) |
|------|---------------------------|----------------------------------|
| batch_size | 与 BTS 一致，常用 16 量级 | 16 |
| ray_batch_size | 同 BTS，patch 模式 | 4096 |
| patch_size | 8×8 | 8×8 |
| n_coarse | 64（均匀/逆深度采样） | 64（32 surface + 32 global，DA3 自适应） |
| mlp_coarse | n_blocks=0, d_hidden=64 | n_blocks=0, d_hidden=64 |
| 学习率 / 调度 | 1e-4，step decay（如 120k step ×0.1） | 1e-4，StepLR 120000 step ×0.1 |
| 深度采样方式 | 均匀或逆深度分层采样 | DA3 引导的自适应采样（表面+全局） |

### 1.3 核心差异：深度采样策略

- **原始 S4C**：每条射线 64 个点均在 [z_near, z_far] 上**均匀或逆深度**分布，所有视图一致。
- **本项目**：引入 DA3 深度先验，**表面附近 32 点 + 全局 32 点**；若 DA3 不可靠（如鱼眼零深度），会退化成“表面”挤在近处的畸形分布，与 S4C 行为不一致，见《loss震荡分析原因》中鱼眼退化分析。

### 1.4 关键实例射线占比（2D 射线选择）

- 原始 S4C 与本项目在 **2D 射线（像素）选择** 上一致：均使用 **PatchRaySampler**，对视图和 patch 位置用 **均匀随机**（torch.randint）采样。
- DA3 自适应只影响**沿射线的 3D 深度采样**，不改变“哪些像素被选为射线”。
- 因此，**关键实例（车、人等）上的射线占比** 在两者间**基本一致**；ViPOcc 论文中给出的 S4C 关键实例射线占比约 **7.17%**，本项目在未改 2D 采样的前提下可视为同一量级。

## 二、与 ViPOcc 的对比

### 2.1 ViPOcc 来源

- **论文**：ViPOcc (arXiv:2412.11210)，单视图 3D 占据预测，结合 VFM 与语义引导采样。

### 2.2 方法差异概览

| 维度 | ViPOcc | 本项目 (S4C + DA3) |
|------|--------|---------------------|
| 任务 | 单视图 3D 占据 | 多视图 NeRF 重建 + 语义（SSC） |
| 深度/几何先验 | Depth Anything V2 + Grounded-SAM 等 VFM | DA3 深度图（离线/在线） |
| 2D 射线采样 | SNOG（语义/实例引导）按语义/实例密度采样 | 均匀随机 patch 采样 |
| 3D 深度采样 | 沿射线按深度预测与不确定性采样 | DA3 引导的表面+全局 64 点 |
| 训练数据与 batch | 论文设定（单视图、batch 等） | KITTI-360 多视图，batch_size=16 |

### 2.3 训练设置要点（ViPOcc）

- **双深度分支**：一个与占据头共享，一个独立，用于深度监督与采样。
- **SNOG 采样器**：在 2D 上按语义/实例重要性对像素（射线）进行非均匀采样，提高关键实例（车、人）等区域的射线占比。
- **VFM**：Depth Anything V2 做深度，Grounded-SAM 等做语义/实例，用于构建 SNOG 与监督。

### 2.4 与本项目的可比与不可比之处

- **可比**：都使用单目深度先验（ViPOcc 用 DA2，本项目用 DA3）参与几何/采样；都关心沿射线的 3D 采样和 2D 射线选择对训练的影响。
- **不可比/差异**：ViPOcc 的 2D 射线采样是 SNOG（语义/实例引导），本项目是均匀 patch；因此 ViPOcc 可主动提高关键实例射线占比，本项目在未改 2D 采样前与 S4C 一致（约 7.17%）。任务与网络结构不同（占据 vs NeRF 重建+分割），batch、数据增强、loss 设计等仅作参考，不能直接对齐。

---

## 三、对比小结

| 对比项 | 原始 S4C | 本项目 | ViPOcc |
|--------|----------|--------|--------|
| 2D 射线选择 | 均匀随机 patch | 均匀随机 patch | SNOG（语义/实例引导） |
| 3D 深度采样 | 均匀/逆深度 64 点 | DA3 自适应 32+32 | 深度+不确定性引导 |
| 关键实例射线占比 | ~7.17% | ~7.17%（同 S4C） | 通过 SNOG 提高 |
| 鱼眼/无深度视图 | 均匀采样，无退化 | 若用 DA3 零深度会退化 | 单视图设定不同 |

若要向 ViPOcc 靠拢，需要引入**对 2D 射线位置的改动**（如类似 SNOG 的语义/实例引导采样）；当前仅 DA3 自适应 3D 采样的实现，在 2D 射线占比上与 S4C 一致。
