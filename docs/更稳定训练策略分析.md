# 更稳定训练策略分析

> 在不改动 2D 射线采样（不引入 ViPOcc 式 SNOG 等）的前提下，为 loss 稳定下降提出的策略与优先级。

---

## 一、策略总览与优先级

| 优先级 | 策略 | 目标 | 预期效果 |
|--------|------|------|----------|
| **P1** | 修复鱼眼视图采样退化 | 避免无效 DA3 深度导致表面采样挤在近处 | 消除主要结构性梯度噪声，loss 有望明显下降 |
| **P2** | 修复 depth_mode / 置信度 | 低置信度或无效深度回退全局逆深度采样 | 自适应采样更稳健，减少错误先验干扰 |
| **P3** | 鱼眼在 loss 中的权重（可选） | 降低鱼眼视图对 loss 的贡献 | 进一步减轻鱼眼噪声，可选 |
| **P4** | 实现学习率 Warmup | 前若干 step 线性升 LR | 早期训练更稳定，曲线更平滑 |
| **P5** | 调整 batch_size / ray_batch_size | 提高单场景覆盖、平衡梯度方差 | 收敛更稳、信息利用更充分 |
| **P6** | 梯度裁剪 | 限制梯度范数 | 防止偶发大梯度破坏训练 |

---

## 二、P1：修复鱼眼视图采样退化（必做）

**问题**：鱼眼相机 DA3 深度为 0，被 clamp 到 z_near=3 后，32 个 surface 点全在 [3, 4] m，采样严重退化。

**做法**：在 `NeRFRenderer.sample_adaptive()` 中，对“无效 DA3 深度”的射线**回退为与 S4C 一致的全局逆深度分层采样**（即调用 `sample_coarse(rays_subset)`）。

**采样方式说明**：本项目中 `lindisp=True`，`sample_coarse()` 在**逆深度（disparity）空间**线性划分 + 分层抖动，公式为  
`z = 1 / (1/near * (1-t) + 1/far * t)`，t 在 [0,1] 均匀加 jitter。  
这是**逆深度空间分层采样**，不是“深度空间均匀”，与原始 S4C/BTS 的 coarse 实现一致。

**实现要点**：

- 定义无效深度：例如 `da3_depths <= near + eps`（或深度≈0）。
- 对满足条件的射线调用 `sample_coarse(rays_subset)`，得到 64 点逆深度分层采样。
- 将其写回 `all_samples` 中对应射线位置，其余射线仍走现有 surface+global 自适应逻辑。
- 若与“低置信度回退”共用逻辑，可统一为“无效或低置信 → sample_coarse（全局逆深度）”。

**验证**：从头训练，观察 loss 是否出现明显下降趋势；对比修复前后鱼眼视图对应的 loss 分量或 invalid 比例。

---

## 三、P2：修复 depth_mode 与置信度（高优先级）

**问题**：`depth_mode="online"` 未传入 Dataset，`online_depth_generation` 未在 model_conf 中设置，导致始终用离线 DA3、`low_conf_mask=None`，低置信度回退未生效。

**方案 A（完整修复）**：

- 在 `data_util.py` 中向 `Kitti360Dataset` 传递 `depth_mode`（及 da3 相关参数）。
- 在 `model_conf` 或 trainer 配置中设置 `online_depth_generation: true`，使 DA3 在线推理与置信度输出生效，`low_conf_mask` 非空，低置信区域自动走均匀采样。

**方案 B（最小改动）**：不改数据管线，仅在 `sample_adaptive()` 内用启发式构造“等效低置信”：

- 将 DA3 深度为 0 或接近 z_near 的射线视为低置信；
- 将这些射线与 P1 一起，统一回退到 `sample_coarse()`（全局逆深度分层采样）。

**建议**：先做方案 B 与 P1 合并实现，快速验证；再视需要做方案 A 接入真实置信度。

---

## 四、P3：鱼眼视图在 loss 中的权重（可选）

**问题**：8 视图中 4 个为 loss 视图，其中包含鱼眼；当前所有视图等权，鱼眼噪声会拉高 loss 方差。

**做法**（可选其一）：

- **选项 A**：在 `PatchRaySampler.sample()` 中，对视图索引 `patch_coords_v` 做**非均匀采样**，降低采样到鱼眼视图的概率（例如透视:鱼眼 ≈ 3:1）。
- **选项 B**：在 loss 中按视图加权，对来自鱼眼视图的射线降低权重（需在 loss 侧传入视图 id 并加权）。

**建议**：先完成 P1（鱼眼回退均匀采样），鱼眼射线梯度质量会明显改善；若仍觉方差大，再考虑 P3。

---

## 五、P4：实现学习率 Warmup

**问题**：`warmup_steps` 在 default.yaml 中配置但 `make_scheduler` 未读取，训练从 step 1 起即为 1e-4。

**做法**：

- 在 `scheduler.py` 的 `make_scheduler()` 中读取 `config.get("warmup_steps", 0)`。
- 若 `warmup_steps > 0`，使用 `SequentialLR`：前 `warmup_steps` 步用 `LambdaLR` 做线性 warmup（lr 从 0 或小值线性增至 base_lr），之后接原有 `StepLR`。
- 在 `exp_kitti_360.yaml` 的 `scheduler` 下显式设置 `warmup_steps: 10000`（或 5000），与 default 一致或略短。

**效果**：前几千步梯度更平滑，减少早期震荡，有利于曲线稳定下降。

---

## 六、P5：调整 batch_size / ray_batch_size

**问题**：当前每场景仅约 3.3% 像素被采样，单场景信号偏弱。

**做法**：在显存允许下：

- 将 `batch_size` 从 16 降到 **8**（或 4）；
- 将 `ray_batch_size` 从 4096 提到 **8192**（或 16384）；
- 可选：`patch_size` 保持 8 或略增到 16，以兼顾 SSIM。

**效果**：单场景覆盖率提高，每步梯度更反映单场景结构，收敛往往更稳；需监控显存与每 step 时间。

---

## 七、P6：梯度裁剪

**问题**：未做梯度裁剪，偶发大梯度可能破坏参数。

**做法**：在 `base_trainer.py` 的 `train_step` 中，`scaler.scale(loss).backward()` 之后、`scaler.step(optimizer)` 之前：

- 若使用 AMP：先 `scaler.unscale_(optimizer)`，再 `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)`，再 `scaler.step(optimizer)`。
- 若不使用 AMP：直接 `clip_grad_norm_(model.parameters(), max_norm=1.0)` 再 `optimizer.step()`。

**效果**：限制偶发大梯度，训练更稳，对收敛曲线有轻微“平滑”作用。

---

## 八、建议实施顺序

1. **先做 P1**（鱼眼回退均匀采样），必要时与 P2 方案 B 合并（无效/零深度统一回退）。
2. **从头训练**若干 epoch，看 loss 是否出现**明显下降趋势**。
3. 若仍不理想：**加 P2 方案 A**（接入在线 DA3 + 置信度）和 **P4（Warmup）**。
4. 若曲线仍抖动或收敛慢：再考虑 **P5（batch/ray_batch）**、**P6（梯度裁剪）**，以及可选的 **P3（鱼眼权重）**。

P1 是当前与原始 S4C 行为差异最大的一环，优先修复最能对准“loss 不降”的根本原因。
