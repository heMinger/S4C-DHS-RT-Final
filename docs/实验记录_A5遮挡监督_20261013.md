## 1. 动机与问题

当前基线（S4C + DHS 自适应采样 + Ray Transformer）在 KITTI-360 上：

- 语义 mIoU：**略有提升**
- 几何指标：**回退**（Recall −4 ~ −6，几何 IoU −1 ~ −1.7）

问题本质：DHS 采样只把「采样点」放在 DA3 深度附近（*在哪里采*），但从未用 DA3 深度做**监督**（*采对了没有*）。网络自由地在前景/背景分配 alpha，导致深度表面位置不准确、几何退化。

## 2. 假设

用 DA3 深度作为**伪表面先验**做三态遮挡监督，可以约束沿射线的 alpha 质量分布，让：
- 自由空间（表面之前）→ 累积权重收敛到 0
- 表面带 → 累积权重收敛到 1
从而恢复几何（Recall / 几何 IoU），同时不破坏语义。

## 3. 方法：三态遮挡监督

对每条拥有**有效且高置信** DA3 深度 d* 的射线：

| 区间 | 定义 | 监督目标 |
|------|------|----------|
| 自由空间 | z < d* − 0.5m | 累积权重 → 0 |
| 表面带 | \|z − d*\| ≤ 0.5m | 累积权重 → 1 |
| 表面之后 | z > d* + 0.5m | 屏蔽（未知，不监督） |

损失：`loss = mean( free_sum² + (1 − surf_sum)² )`，仅对有效射线取平均。

有效射线判定（与 `sample_adaptive` 的回退掩码一致）：
- `d* > z_near (3.0m)`
- 归一化置信度 `norm_conf = ((conf − 1.0) / 5.5535).clamp(0.1, 1.0) ≥ conf_threshold (0.2)`

## 4. 代码改动

| 文件 | 改动 |
|------|------|
| `models/bts/model/loss.py` | 新增 `occlusion_supervision_loss()`；`ReconstructionLoss` 增加 `lambda_occlusion` 权重、`loss_occlusion` 指标、损失累加 |

## 5. 关键超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `lambda_occlusion` | 0.1 | 遮挡损失权重（初始值，可调） |
| `free_space_margin` | 0.5m | 自由空间边界 |
| `surface_band` | 0.5m | 表面带半宽 |
| `conf_threshold` | 0.2 | 置信度阈值（复用采样阈值） |
| `conf_epsilon` | 0.1 | 归一化置信度下界（复用） |

其余训练配置不变：60 epoch，batch 8×accum2，lr 1e-4，192×640，z∈[3,80]m 逆深度，64 pts/ray（32 表面 + 32 全局）。
