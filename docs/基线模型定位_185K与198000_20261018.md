## 完整 SSCBench 三范围结果（同口径）

来源：`qualitative_metric_search/{s4c,dhs,rt}.csv`（415 个共享测试帧，聚合 tp/fp/fn）。

评估口径统一：`sigma_cutoff=0.25`、`VOXEL_SIZE=0.1`、`USE_ADDITIONAL_INVALIDS=False`、`USE_GROW=False`、`PSEUDO_RAY_K=64`、2000 帧 SSCBench split。

| 方法 / checkpoint | 12.8m | 25.6m | 51.2m |

## 关键解读

1. **RT 的收益主要在语义（mIoU）**：12.8m 从 DHS 的 14.99 → 16.12（+1.13），且 Recall 明显提升（53.53→57.66），与论文主张"RT 改善语义/侧视"一致。
2. **占位 IoU 三者在 26~29 之间、差距很小**：这套 `invFalse_0.1_noGrow` 口径下三者都很低。之前看到的 50+ IoU（52.33/44.78/40.40）是 `invTrue_0.2_mpTrue`（排除遮挡 + voxel 0.2 + grow）的**另一套口径**，不可直接比较。
3. **185K 不是从零训练**：它从 DHS-only 218000 续训（`reset_training_state=true`），是"DHS 权重 + 打开 RT 继续训"的设定。若要"纯 DHS+RT 从零"的对照，需要重新训练。

## 需要注意的口径陷阱

- 之前引用的"基线终值 a1_lidar=0.847 / abs_rel=0.126 / IoU@12.8=59.22 / mIoU=16.65"来自 `docs/DA3v3生成质量报告与训练设计.md`，那是 **ONLINE（在线深度）模型**，不是 7b81b11 的 offline 基线，**不能作为 DHS/DHS+RT 的对照**。
- 进度条显示的 IoU（如 A5 的 30.42）是 **51.2m** 范围的 partial（16/2000 帧），不是 12.8m。
