## 1. 问题背景

E1 (S4C + DHS 自适应采样 + RT 读图像特征) 在 2566 样本上的三维评估:

| 距离 | IoU | Precision | Recall | mIoU |
|------|-----|-----------|--------|------|
| 12.8m | 52.42 | 60.82 | 79.16 | 16.41 |
| 25.6m | 43.97 | 50.79 | 76.61 | 13.25 |
| 51.2m | 38.08 | 44.39 | 72.82 | 9.74 |

核心疑问: **为什么 Recall 随距离下降? 是"采样点误差"还是"预测深度误差"?**

为定量分解, 编写纯 CPU 诊断脚本 `scripts/diagnose_sampling_depth_error.py`, 把三种深度区分开:

- `d_da3` : DA3 先验深度 (自适应采样的中心), 轴向 z → 转沿射线距离, 米
- `d_pred`: 模型渲染深度 (预测值)
- `d_gt`  : LiDAR 真值深度, 轴向 z → 转沿射线距离, 米

    * 采样点误差 = |d_da3 - d_gt|   (脚本统计, 与模型无关, 固定值)
    * 预测深度误差 = |d_pred - d_gt| (训练 validate 已记录 a1_lidar / abs_rel_lidar)

## 2. 诊断脚本 (v2): 严格复现训练采样

`scripts/diagnose_sampling_depth_error.py` (纯 CPU, 无需 GPU/模型), 逐行复现
`models/common/render/nerf.py` 的 `sample_adaptive` 与 `ray_sampler.py` 的
DA3 轴向 z → 沿射线距离 (`/cos_theta`) 转换:

```
1. norm_conf        = clip((conf - 1) / 5.5535, conf_epsilon=0.1, 1.0)
2. effective_absrel = absrel_prior(0.12) / norm_conf         (有 conf 图时)
                      absrel_prior(0.12)                     (无 conf 图时)
3. sigma            = max(min_thickness=0.5, effective_absrel * d_ray)
4. 表面采样: n_surface 点均匀铺在 [d_ray-2σ, d_ray+2σ], 裁剪到 [z_near=3, z_far=80]
5. 全局采样: n_global 点逆深度均匀铺在 [3, 80] (lindisp=true)
6. 回退 (fallback): norm_conf < conf_threshold(0.2) 或 d_ray < z_near+0.01
   → 全部 n_surface+n_global 个点走全局逆深度采样 (sample_coarse), 无表面窗口
```

cosθ 由归一化内参 K 复现 `unproj_map(...)[...,2]`:
`cos = 1 / sqrt(((x-cx)/fx)^2 + ((y-cy)/fy)^2 + 1)`。

参数可调: `--n-surface 32 --n-global 32 --voxel-size 0.2 --z-near 3 --z-far 80`
`--conf-threshold 0.2 --no-conf`。

### 2.1 旧版脚本的 6 处错误 (已修正)

| # | 旧版错误 | 修正后 |
|---|---------|--------|
| ① | 不复现低置信度回退: norm_conf<0.2 时真实代码走 64 点全局采样, 旧版仍统计"虚构的 32 点表面窗口" | 加入 `fallback_mask = low_conf \| invalid_depth`, 回退像素按 64 点全局采样统计 |
| ② | 无 near/far 裁剪: 4σ/32 可能远大于实际窗口宽 | 窗口裁剪到 [z_near, z_far], 层宽 = d_max-d_min |
| ③ | 无置信图时用 `ones_like(da3)` → 归一化成 0.1 → effective_absrel=1.2 (把窗口放大 10×) | 真实代码无 conf 时直接 `effective_absrel=0.12`, 新增 `--no-conf` 复现 |
| ④ | a1 公式错误: `rel_err<0.25` 非标准 a1, 会把部分低估深度误算为通过 | 改用标准对称 `ratio=max(d1/d2,d2/d1)<1.25` |
| ⑤ | 用轴向 z 计算沿射线间距, 无内参/cosθ | 所有绝对量 (RMSE/σ/间距/窗口) 换算到沿射线方向 |
| ⑥ | 把间距达标率叫 "Recall 结构上限" | SSCBench 在稠密体素网格上直接查 MLP, 训练未采到的位置也能被预测; 该上限不存在, 达标率仅是"训练信号是否覆盖到体素级分辨率"的度量 |

## 4. 关键发现 (修正后)

### 4.1 主因重新定位: 低置信度回退, 不是 σ 爆炸

**旧结论 (已废弃)**: 远距离低 conf → norm_conf 压到 0.1 → effective_absrel=1.2 →
σ=1.2d → 带宽 4.8d → 间距 5.04m。这个链条是错误的, 原因:

> 当 `norm_conf < conf_threshold(0.2)` 时, 这些像素**根本不用表面窗口** ——
> `sample_adaptive` 把它们全部替换为 64 点全局逆深度采样 (`sample_coarse`)。
> 所以 effective_absrel=1.2 的 σ 从不被使用; 真正发生的是**表面采样被完全关闭**。

**修正后的正确链条**:
1. 远距离 DA3 置信度低 → `norm_conf < 0.2` → **回退** (占远距离像素 95.35%)。
2. 回退像素用 64 点全局逆深度采样, 远距离回退间距 **7.80m** (体素 0.2m 的 39×)。
3. 仅 4.65% 高置信远距离像素使用表面窗口, 其 σ∈[0.12d, 0.6d], 间距均值 0.674m。
4. 高置信远距离像素的 DA3 中心仍偏 (2σ命中率仅 34.71%, abs_rel 20.9%)。

**结论: 远距离覆盖不足的头号原因是"回退机制把 95% 的远距离表面采样关了",
σ 缩放是次要因素 (只影响 4.65% 高置信像素, 且被裁剪 [3,80] 限制)。**

### 4.2 三个距离段的解读

| 距离段 | 回退率 | 主要矛盾 |
|--------|--------|---------|
| <12.8m | 6.5% | 正常: 表面窗口 σ=0.12d, 间距 0.157m ≤ 体素, 达标 80% |
| 12.8-25.6m | 39.0% | 过渡: 39% 回退; 非回退间距 0.578m (2.9×体素) |
| >25.6m | 95.4% | 崩坏: 95% 回退走 64 点全局, 回退间距 7.80m (39×体素) |

### 4.3 修正后的表面间距 (对比旧版)

| 距离桶 | 旧版表面间距 (错误) | 修正后表面间距 (非回退) |
|--------|--------------------|------------------------|
| <12.8  | 0.218m | 0.157m |
| 12.8-25.6 | 1.546m | 0.578m |
| >25.6  | 5.040m | 0.674m |

远距离 5.04m→0.674m 的差异来自: ① 旧版把回退像素的"虚假 32 点窗口"也计入;
② 旧版无 [3,80] 裁剪; ③ 旧版无 cosθ 换算。修正后远距离非回退像素的间距与
σ∈[0.12d,0.6d] 一致 (裁剪限制在 80m, 故 0.674m)。

### 4.4 表面达标率的物理上限 (与 conf 无关)

即使完全去掉回退 (`--no-conf`), 表面间距 = 0.48d/32 = 0.015d 是"σ=0.12d、
32 点、4σ 窗口"的固有限制:

```
间距 ≤ 体素 0.2m  ⟺  0.015d ≤ 0.2  ⟺  d ≤ 13.3m
```

所以 **d>13.3m 的射线, 无论置信度多高, 32 点表面采样都无法达到体素级分辨率**。
这就是 `--no-conf` 下 12.8-25.6m 表面达标仅 12.35%、>25.6m 仅 3.81% 的原因。

> ⚠️ 但这**不是 Recall 的硬上限** (旧版 §4.3 的"结构性上限"说法已废弃):
> SSCBench 评估在稠密体素网格上直接查询 MLP, 训练未采到的位置也能被预测。
> 达标率刻画的是**训练信号 (梯度) 是否覆盖到体素级**, 而非评估时能否查询。

## 5. 关键结论与方向

### 5.1 约束

总采样点数 `n_surface + n_global = 64` 必须保持, 否则无法与 S4C baseline 公平对比。
可调: surface/global 比例、conf 归一化 (conf_epsilon / conf_threshold)、σ 公式。

> **补充 (2026-10-30 代码核对)**: DHS 的**低置信度回退分支与 S4C 的真实采样数值等价** ——
> 回退时 `sample_adaptive` 调用的正是 S4C 使用的同一个 `sample_coarse` (64 点、逆深度分层、
> lindisp=true、[3,80]), 且无额外采样阶段。因此:
> - "远处全局采样稀疏 / 回退间距 7.80m" 是 **S4C 与 Ours 共同**的基线性质, 不能单独
>   用它解释 Ours 相对 S4C 的退化。
> - 本文 §4.1 的"回退关掉 95% 远距离表面采样"仍可解释 **Ours 无法超过 S4C 远距离
>   Recall**, 但解释不了 **Ours 比 S4C 还差** 的部分; 后者需由 DHS 非回退采样 + RT
>   的净负贡献解释, 见 `docs/漏检定位与RT密度诊断_三模型对比_20261030.md` (Step 2)。

### 5.2 优先级排序 (修正后)

| 优先级 | 方案 | 做法 | 说明 |
|-------|------|------|------|
| **P0** | 覆盖诊断 | 逐桶量化回退率/间距/达标率 | ✅ 已完成 (修正后: 远距离回退率 95.35%) |
| **P2** | 修复低置信度回退 | ① `conf_epsilon` 0.1→0.5 (norm_conf 下限抬到 0.5, effective_absrel 上限降到 0.24, 且 norm_conf≥0.5 永不触发 conf_threshold=0.2 回退); 或 ② `conf_threshold` 0.2→0 (关闭 conf 回退); 或 ③ 两者组合 | **直击主因**: 95% 远距离像素因回退关了表面采样 |
| **P1** | surface/global 比例消融 | 48/16 或 56/8 (保 64 点) | 次要: 只帮非回退像素, 且 d>13.3m 的 0.015d 物理上限仍需更多表面点 |
| **P3** | 密度蒸馏/伪监督 | LiDAR 先验填远处体素 | 本质解法, P2 放宽 conf 后仍不足时的出路 |

> **修正后 P2 > P1 > E2**: P2 现在同时解决"回退"与"σ 缩放"两个问题 —— 把
> `conf_epsilon` 抬到 0.5 后, norm_conf∈[0.5,1], 既消除了 conf 回退 (norm_conf
> 永不低于 0.2), 又把 effective_absrel 上限从 1.2 压到 0.24。这一步比 P1 挪点
> (只作用于非回退像素) 优先级高得多。

### 5.3 P2 候选方案对比

| 方案 | 回退率变化 | σ 上限 | 风险 |
|------|-----------|--------|------|
| 现状 | 远 95.4% | 1.2d (但被回退架空) | 远距离表面采样形同虚设 |
| conf_epsilon=0.5 | 远 ~0% | 0.24d | 低 conf 区域失去自适应, 统一 σ=0.24d; 需监控 2σ命中率 |
| conf_threshold=0 | 远 ~0% | 1.2d (σ 爆炸回归) | 回到旧版"σ=1.2d"问题, 窗口过宽、间距过大 |
| 组合 (ε=0.3, th=0.15) | 远 ~0% | 0.4d | 折中, 需消融 |

**推荐 P2 首选**: `conf_epsilon` 0.1 → 0.5 (单旋钮, 同时消除回退 + 限制 σ)。
代价是放弃"低 conf → 更宽窗口"的自适应意图; 但既然低 conf 当前只能触发回退,
这个自适应从未真正生效, 收紧是净收益。

### 5.4 P1 (覆盖) vs E2 (预测) 优先级

两者**正交**:
- **P2/P1 解决"训练采样是否覆盖"** —— 回退 + 间距决定训练信号覆盖。
- **E2 解决"有点但 sigma 预测偏低"** (预测侧, ρ_base 输入 RT)。

**结论: 覆盖侧 (P2, 优先) > 预测侧 (E2)**。先修 P2 消除回退, 让远距离表面采样
重新生效; 否则 E2 在远距离被"根本没采到点"卡死。

a1(1.25):  ratio = max(d_pred/d_gt, d_gt/d_pred) < 1.25
