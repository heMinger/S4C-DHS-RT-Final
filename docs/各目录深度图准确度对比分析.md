# 各目录深度图准确度对比分析

> 以 LiDAR 投影深度为真值，对 data_2d_depth_da3、data_2d_depth_da3_v2、data_2d_depth_da3_v3 的准确度做对比与解读。  
> 数值来源于脚本 `dino-da3-adaptive-sampling1/scripts/test_depth_vs_lidar.py`（及小规模多视图测试）的典型结果；实际请以本地运行为准。

---

## 一、评估设置

- **真值**：KITTI-360 的 LiDAR 点云投影到 rectified cam0 图像平面，得到**稀疏深度图**（仅部分像素有值）。  
- **评估范围**：在有效 LiDAR 像素上，深度区间约 [1, 80] m。  
- **指标**：  
  - **RAW**：预测深度与 LiDAR 直接比较 → 反映**绝对公制精度**。  
  - **ALIGNED**：先对预测做 **median scaling**（scale = median(LiDAR / pred)）再比较 → 反映**相对深度结构**。  
  - **时间一致性**：同序列多帧的 mean depth、CoV、帧间 jitter。

---

## 二、各目录准确度概览

### 2.1 data_2d_depth_da3（OLD）

| 类型 | 指标 | 典型值 | 说明 |
|------|------|--------|------|
| **RAW** | abs_rel | ~0.39 | 绝对误差大，因尺度系统偏大 |
| | sq_rel | - | 平方相对误差 |
| | rmse | ~5.6 m | 米制偏差明显 |
| | rmse_log | - | 对数空间 RMSE |
| | delta1 (δ<1.25) | 较低 | 未对齐时比例差 |
| | delta2 / delta3 | - | 同上 |
| | **median_ratio** | **~0.73 ± 0.03** | LiDAR/预测中位数比 < 1 → 预测深度约**偏大 37%** |
| **ALIGNED** | abs_rel | **~0.10** | 相对深度结构好 |
| | rmse | 下降 | 对齐后米制误差减小 |
| | delta1 | **~0.88** | 约 88% 像素在 1.25 倍以内 |
| | align_scale | 帧间相对稳定 | 约 0.73 量级 |
| **时间** | mean depth | 帧间有波动 | - |
| | CoV | ~0.32 | 尺度有一定稳定性但不理想 |
| | Frame jitter (max) | ~32 m | 帧间平均深度差最大约 32 m |

**小结**：OLD 与 LiDAR 相比**尺度系统性偏大**，但**相对深度质量较好**；时间上同一序列内尚可，适合作为“大致稳定”的离线先验用于当前 S4C 训练。

---

### 2.2 data_2d_depth_da3_v2（NEW_v2）

| 类型 | 指标 | 典型表现 | 说明 |
|------|------|----------|------|
| **RAW** | abs_rel | 均值差且**方差大** | 帧间尺度不一致 |
| | rmse | 大且波动 | 无稳定公制尺度 |
| | median_ratio | **帧间差异大** | 无统一比例 |
| **ALIGNED** | abs_rel | 与 OLD 同量级 ~0.10 | 单帧相对结构尚可 |
| | delta1 | ~0.88 | 对齐后与 OLD 接近 |
| | align_scale | **帧间变化大** | 反映每帧尺度不同 |
| **时间** | CoV | **高于 OLD** | 尺度随帧漂移明显 |
| | Frame jitter | 大于 OLD | 不适合跨帧一致应用 |

**小结**：v2 相对深度单帧尚可，但**绝对尺度与时间一致性差**，主因是 DA3 内部未固定种子的随机对齐导致逐帧 scale 不同；不做推荐用于依赖尺度或时间一致性的任务。

---

### 2.3 data_2d_depth_da3_v3（多视图 + GT 位姿，若已生成）

| 类型 | 指标 | 预期/小规模测试 | 说明 |
|------|------|-----------------|------|
| **RAW** | abs_rel | **明显低于 OLD/v2** | Umeyama 对齐到公制 |
| | rmse | 显著下降 | 米制准确 |
| | median_ratio | **接近 1.0** | 无系统性尺度偏 |
| **ALIGNED** | abs_rel | ≤ OLD | 相对结构保持或更好 |
| | align_scale | 帧间稳定 ~1.0 | 尺度一致 |
| **时间** | CoV | **低** | 多帧尺度一致 |
| | Frame jitter | **小** | 适合序列/训练 |

**小结**：v3 在**绝对精度**和**时间一致性**上优于 OLD 和 v2；相对深度至少不差。需在完整生成 v3 后跑 `test_depth_vs_lidar.py` 得到本机数值。

## 四、如何复现与更新本表

1. **OLD / v2 / v3 与 LiDAR 对比**（无 GPU 即可）：  
   ```bash
   cd /home/lmh/dino-da3-adaptive-sampling1
   python scripts/test_depth_vs_lidar.py \
     --data_path /mnt/remote_data/lmh_data/KITTI360 \
     --seq 2013_05_28_drive_0000_sync \
     --n_frames 50 --depth_scale 256.0
   ```  
   脚本会按存在目录自动选择 OLD / NEW_v2 / NEW_v3 并输出 RAW、ALIGNED、时间一致性。

2. **小规模多视图 + 与 OLD/v2 对比**（需 GPU 跑少量 v3 帧）：  
   ```bash
   python scripts/test_multiview_small.py \
     --data_path /mnt/remote_data/lmh_data/KITTI360 \
     --seq 2013_05_28_drive_0000_sync
   ```  
   会得到 v3_multiview / v3_single / OLD_da3 / NEW_v2 的并排指标。

3. 将上述输出中的均值、标准差填入本表，即可得到你环境下的《各目录深度图准确度对比分析》终版。
