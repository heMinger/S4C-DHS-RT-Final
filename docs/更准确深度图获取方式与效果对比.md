# 更准确深度图获取方式与效果对比

> 在 KITTI-360 上对比单图 DA3、多视图 DA3（含位姿）等方式的差异及效果。

---

## 一、方式概览

| 方式 | 脚本/入口 | 输入 | 位姿/内参 | 尺度性质 | 时间一致性 |
|------|-----------|------|-----------|----------|------------|
| **单图 DA3（OLD/v2）** | 批量单图推理 | 单张图 | 无 | 相对/仿射，逐帧随机 | 差 |
| **多视图 DA3 + GT 位姿（v3）** | `generate_da3_depth_multiview.py` | 连续多帧 + extrinsics/intrinsics | KITTI-360 GT | 公制，Umeyama 对齐 | 好 |
| **在线 DA3（训练时）** | `DA3DepthGenerator` | 当前 batch 图像 | 无 | 与单图相同 | 仅当前 batch |

---

## 二、更准确方式：多视图 + 真值位姿（v3）

### 2.1 思路

- **单图问题**：不传 `extrinsics`/`intrinsics` 时，DA3 不做与场景公制对齐，输出尺度任意且帧间不一致；内部还有未固定种子的随机采样，导致逐帧 scale 不同。
- **改进**：对连续多帧**同时**送入 DA3，并传入 KITTI-360 的 **cam0_to_world**（及由标定推出的 image_01 位姿）和 **perspective 内参**。  
  DA3 内部通过 **Umeyama Sim(3) 对齐**预测位姿到真值位姿，得到**统一公制尺度**，并可用**固定随机种子**保证可复现。

### 2.2 实现要点（generate_da3_depth_multiview.py）

- **位姿**：读 `poses/{seq}/cam0_to_world.txt`，image_01 由 cam0 + 标定 baseline 推出。  
- **内参**：从 `calibration/perspective.txt` 的 `P_rect_00` / `P_rect_01` 取 3×3 K。  
- **多视图**：按 `window_size`（如 7）将连续帧分组，每组一次 `model.inference(image=paths, extrinsics=..., intrinsics=..., align_to_input_ext_scale=True)`。  
- **种子**：脚本内 `set_seed(42)`，避免 DA3 内部随机采样导致尺度抖动。  
- **输出**：与 OLD/v2 相同的目录结构，uint16 PNG，`depth_m × 256`；可选写 confidence。

### 2.3 使用方式

```bash
cd /home/lmh/dino-da3-adaptive-sampling1
python scripts/generate_da3_depth_multiview.py \
    --data_path /mnt/remote_data/lmh_data/KITTI360 \
    --output_root /mnt/remote_data/lmh_data/KITTI360/data_2d_depth_da3_v3 \
    --window_size 7 \
    --compare_lidar   # 可选：前几帧对比 LiDAR
```

## 三、效果差异对比（预期与实测方向）

### 3.1 绝对尺度（RAW，与 LiDAR 直接比）

| 指标 | 单图 OLD/v2 | 多视图 v3（预期/小规模测试） |
|------|-------------|------------------------------|
| **abs_rel** | OLD ~0.39，v2 更差且波动大 | 明显优于单图（scale 正确） |
| **RMSE** | OLD ~5.6 m | 预期显著下降 |
| **median_ratio** | OLD ~0.73（偏大 37%） | 接近 1.0 |
| **δ<1.25** | 低（尺度偏） | 预期明显提升 |

### 3.2 相对深度（ALIGNED，median scaling 后）

- OLD/v2：median 后 abs_rel 约 0.10，δ<1.25 约 0.88，说明**相对结构**尚可。  
- v3：在公制已对齐的前提下，相对结构应保持或略优于单图，且**帧间 align_scale 稳定**。

### 3.3 时间一致性（同序列多帧）

| 指标 | 单图 OLD | 单图 v2 | 多视图 v3 |
|------|----------|--------|-----------|
| **CoV (mean depth)** | ~0.32 | 更高 | 预期明显更低 |
| **Frame jitter** | 最大约 32 m | 更大 | 预期 < 数米 |
| **适用性** | 训练可作粗先验 | 不推荐 | 训练/评估均可 |

### 3.4 效果差异小结

- **单图（OLD/v2）**：实现简单、无需位姿，但尺度错误且帧间不一致；适合“只要相对深度或粗先验”的场景。  
- **多视图 v3**：需要 GT 位姿与内参、算力更高，但得到**公制一致、时间稳定**的深度，适合训练 S4C 等需要可靠深度先验的管线。  
- **效果差**：主要体现在 **RAW 指标**（abs_rel、RMSE、median_ratio）和**时间一致性**；ALIGNED 指标上 v3 至少不差于单图，且更稳定。

## 四、在训练中的替换建议

- 当前 S4C 实际使用的是 **data_2d_depth_da3**（OLD），`depth_da3_scale=256` 仅做 uint16 编解码，不改变相对/绝对尺度问题。  
- 若希望**更准确的深度先验**（尤其是自适应采样围绕真实表面）：  
  - 使用 **data_2d_depth_da3_v3**（多视图生成）作为 `depth_da3_path`；  
  - 或保持 OLD，适当增大 `absrel_prior` / 增加 global samples，以缓解 OLD 约 37% 偏大带来的采样偏移。  
- 复现与对比时，用 `test_depth_vs_lidar.py` 和 `test_multiview_small.py` 可得到 OLD / v2 / v3 的定量对比（见《各目录深度图准确度对比分析》）。
